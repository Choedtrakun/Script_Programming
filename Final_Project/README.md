### รายละเอียดโปรเจค
แอปช่วยตัดสินใจว่าจะทำอาหารอะไรจากวัตถุดิบที่มีอยู่
ผู้ใช้กรอกวัตถุดิบ ระบบจะค้นหาสูตรจาก TheMealDB API ให้คะแนนตามจำนวนวัตถุดิบที่ตรงกัน
แล้วสุ่มแนะนำเมนูให้

### ฟีเจอร์หลัก
- ตรวจสอบและทำความสะอาดข้อมูลวัตถุดิบที่กรอก
- ค้นหาสูตรอาหารและตัดรายการซ้ำ
- ให้คะแนนความตรงกัน กรอง และสุ่มเลือกเมนู
- ใช้งานได้ทั้งแบบ CLI และเว็บแอป (การ์ดเมนู, หน้ารายละเอียด, ปุ่มสุ่ม, แถบโหลด)
- บันทึกเมนูโปรด

### เทคโนโลยีที่ใช้
- **Backend:** Python 3.11, Flask, requests
- **Frontend:** HTML5, Tailwind CSS, JavaScript
- **Testing / CI:** pytest, GitHub Actions
- **Deployment:** Vercel
